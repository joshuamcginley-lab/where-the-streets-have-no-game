# MacPhisto host script, batch 4: straight from Sydney '93

Lines lifted from MacPhisto's Sydney speech (26/27 Nov 1993), bent to fit the game.
Paste each block into ElevenLabs as one generation (voice: AK - British Posh Well-Spoken Old Man, Eleven v4).

`start-4.mp3`: game start

```
[grandly] People of the living room!
[disapproving] When I came among you...
[scornful] you were squabbling like CHILDREN.
[proud] Now you're all hooked up to one cable...
[dreamy] as close together as stations on a dial.
```

`last-q-3.mp3`: last question

```
[solemn] My time among you... is almost at an END.
[soothing] But don't fear...
[sinister, sweet] I'll be WATCHING you.
[generous] I leave behind video cameras... for each of you.
```

`last-place-3.mp3`: last place

```
[grandly] To whoever is in last place...
[generous] I give you...
[magnanimous] DECIBELS.
[airily] You're welcome.
```

`winner-5.mp3`: final winner

```
[grandly] Congratulations!
[smugly] So now you can dream...
[proud, vain] of being as wealthy and GLAMOROUS as me.
```

`goodnight-3.mp3`: goodnight

```
[weary] Tonight... I'm going to call a TAXI.
[sighs] I'm tired, you see.
[polite] Hello?
[grand, then faltering] My name is Mister... Mista...
[flustered] ...Hello?
[wounded] He wants to go HOME.
```
