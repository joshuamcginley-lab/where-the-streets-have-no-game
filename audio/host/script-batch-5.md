# MacPhisto host script, batch 5: variety for the busy moments

Paste each block into ElevenLabs as one generation (voice: AK - British Posh Well-Spoken Old Man, Eleven v4).
Save each take under the file name shown; the game already knows every name below and starts using a
line as soon as its MP3 and README row are added (then run `python3 tools/host-lines.py`).

Why these: a simulated game night (3–4 players, 3–4 rounds) hears "four in a row" about 3.6 times,
a broken streak and a lead change 1.5–2 times each, last place about 2 times — each of those had one line.
Round starts, winners and the welcome are heard every night, so they need more for night two.

Sources for The Fly material (1992): the ZOO TV screen slogans ("Celebrity is a job", "Death is a career
move", "Ignorance is bliss", "Admit nothing", "Watch more TV", "Believe everything"), Mirror Ball Man's
"I have a vision: television!", The Fly ordering 10,000 pizzas in Detroit (about 100 arrived), "Somebody's
got to play the rock star", and Bono on The Fly's "reports of egomania" (Rolling Stone, 1993). Bono called
MacPhisto The Fly grown old, "fat and playing Las Vegas", so MacPhisto quotes his younger self.
